데이터 안내

이 사이트에서 공개되는 정보와 브라우저 도구의 처리 범위를 설명합니다.

브라우저 도구

JSON, URL, 시간 변환은 현재 페이지의 코드에서 처리합니다. 입력 내용을 분석 API로 전송하거나 로컬 저장소에 저장하는 코드는 포함하지 않았습니다. 클립보드로 복사하는 동작은 사용자가 복사 버튼을 누른 경우에만 수행합니다.

저장하는 설정

밝은·어두운 테마 선택은 이 브라우저의 localStorage에 저장합니다. 저장소 접근이 차단되면 설정 저장 없이 동작합니다. 기기 사이에 동기화하지 않습니다.

사이트 검색

검색을 열면 공개된 콘텐츠로 만든 검색 인덱스를 읽습니다. 검색어를 별도의 분석 서버로 보내는 코드는 없습니다. 호스팅 제공자의 접속 로그나 브라우저 확장 기능까지 통제하는 것은 아닙니다.

공개 자료의 범위

공개용 콘텐츠 폴더만 게시 대상입니다. 초안·예시 표시와 검색 제외 설정은 접근 제어가 아닙니다. 공개 GitHub 저장소에 올린 원본 파일은 웹페이지에서 숨겼더라도 공개될 수 있습니다.

운영자가 확정해야 할 내용

댓글·문의 폼·통계·외부 API를 추가하면 실제 수집 항목과 처리 서비스를 기준으로 이 안내를 갱신해야 합니다. 현재 이 문서는 초기 구현의 동작 설명이며, 법적 적합성을 검토한 개인정보처리방침은 아닙니다.
