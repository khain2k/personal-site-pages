프로젝트 개요

Physical-AI는 아시아경제 교육센터의 산업융합 ‘피지컬 AI’ 로봇 SW 개발 과정과 관련된 공개 저장소입니다. 그 안의 OpenCV 프로젝트는 AMR(자율 이동 로봇)의 도킹 정렬을 주제로, 카메라 영상에서 두 마커의 중점을 찾고 화면 중심과의 차이를 표시합니다.

GitHub 저장소 보기 · 구현 코드 보기

구현한 기능

  • 관심 영역 조절: 화면 중앙을 기준으로 ROI 크기를 트랙바로 조절하고, 해당 영역을 회색조로 변환합니다.
  • 마커 검출: OpenCV SimpleBlobDetector로 검은색 블롭을 찾습니다. 최소 면적과 원형도를 조절하며, 검출된 후보가 두 개 이상이면 크기가 큰 두 개를 선택합니다.
  • 중심 오차 계산: 선택한 두 점의 중점과 화면 중심의 차이 dx, dy를 픽셀 단위로 표시합니다.
  • 정렬 안내: 수평 오차 dx의 절댓값이 15픽셀 미만이면 ALIGN OK, 그 외에는 좌우 이동 힌트를 표시합니다.
  • 실험 영상 저장: S 키로 화면 표시가 포함된 AVI 녹화를 시작하거나 중지하고, Q 키로 종료합니다.

처리 흐름

카메라 입력 → ROI 추출 → 회색조 변환 → 블롭 검출 → 큰 후보 두 개 선택 → 중점·오차 계산 → 화면 안내와 선택적 녹화

영상 처리와 인터랙티브 설정 화면은 Python과 OpenCV로 구현되어 있습니다. 저장소는 NumPy도 의존성으로 안내하지만, 현재 Python 파일에서는 가져오기만 하고 직접 사용하는 연산은 없습니다.

구현 범위와 한계

현재 공개 코드는 영상 기반 정렬 보조 프로토타입입니다. 실제 로봇으로 이동 명령을 보내는 통신·구동 제어는 포함되어 있지 않습니다. dy는 표시되지만 정렬 완료 판단에는 수평 오차만 사용됩니다.

카메라 보정이나 실제 거리 환산은 포함되지 않으며, 크기가 큰 두 블롭이 항상 목표 마커라는 보장도 없습니다. 하드웨어 실험과 도킹 성공률·정밀도·처리 속도는 이번 소개 작성 과정에서 검증하지 않았습니다.
